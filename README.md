## 📌 Project Overview
This repository contains a machine learning web application designed to assist medical professionals and pathologists in classifying breast tumors as **Benign** or **Malignant**. Developed as an academic case study for my ongoing machine learning course at the University of Peradeniya, the project demonstrates the end-to-end deployment of a **Logistic Regression** model using a **Streamlit** user interface.

Instead of predicting risk factors, this tool evaluates microscopic cellular structures derived from Fine Needle Aspirate (FNA) biopsies, providing an instant probability classification based on historical clinical data.

## 🩺 Clinical Features & Inputs
The model evaluates the following 9 cytological characteristics (typically scored on a scale of 1-10 by a pathologist):
* **Clump Thickness:** Assesses if cells are mono-layered or grouped in multi-layered clumps.
* **Uniformity of Cell Size/Shape:** Evaluates consistency in cell morphology.
* **Marginal Adhesion:** Measures how closely the cells on the outside of the epithelial layer adhere to one another.
* **Single Epithelial Cell Size:** Identifies significantly enlarged epithelial cells.
* **Bare Nuclei:** Checks for nuclei not surrounded by cytoplasm.
* **Bland Chromatin:** Rates the uniform "texture" of the nucleus.
* **Normal Nucleoli:** Evaluates the prominence of the nucleolus.
* **Mitoses:** Measures the rate of cell division.

## ⚙️ Key Features
* **Predictive Modeling:** Utilizes a highly interpretable Logistic Regression algorithm optimized for medical binary classification tasks.
* **Interactive UI:** A responsive Streamlit dashboard featuring intuitive sliders for rapid clinical data entry.
* **Real-time Inference:** Translates raw numeric inputs into immediate, human-readable diagnostic predictions.
* **Educational Focus:** Serves as a practical demonstration of supervised learning, feature mapping, and web deployment in a healthcare context.
